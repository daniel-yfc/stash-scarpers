## 3. Why G1 is not yet PASS

The gate requires a reviewer to **independently confirm** that reported XPath functions select the intended nodes on completed, safely captured DOMs, distinguish actual page/redirect outcomes, and bind assertions to the capture inputs.

**Open blocking items:**

- **`G1-BLOCK-01 — No independently accessible raw/adequate replay DOM.** Agent A retained rendered HTML privately for valid security reasons; current published fragments show *selected* nodes, not enough complete ordering/ancestor context to replay `preceding::h2[2]` / `following::h2[1]` or detect a misleading alternative node. No reviewer has shown an independently executed XPath trace on the same raw content.
- **`G1-BLOCK-02 — Navigation and readiness provenance.** Author tooling explicitly lacks HTTP status and redirect chain. The two negatives are **content-404-classified**, not independently verified HTTP 404. A completed CDP-ready product page must be distinguished from a challenge, incomplete hydration and redirect.
- **`G1-BLOCK-03 — Independent signed replay record.** No independent test output with reviewer identity, pinned XPath evaluator/browser versions, exact source SHA(s), per-field expected/actual, node counts, negative-case gate and reviewer verdict has been supplied.

The excerpt newline SHA issue **is NOT a blocking integrity finding** once the 7,899-vs-7,900-byte distinction is recorded; it should be corrected in the author's provenance notes.
